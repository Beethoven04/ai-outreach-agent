The problem. I wanted a master's thesis internship at AI companies in Skåne and Copenhagen. Doing it well by hand means finding the right companies, the right person in each team, a real email address, a personal email for each one, follow-ups and answers, without ever sending a wrong fact or a duplicate. I built a system that does the work and keeps me in control of every decision that matters. It has run in production since October 2026.

How it works

1 · ResearchJob-ad APIs, startup and incubator lists, company team pages
2 · VerifyInfer the address format, confirm the mailbox with the mail server
3 · Write + checkLLM drafts; code rules + LLM rubric check every claim
4 · I approveOne tick in the sheet. Nothing leaves without it
5 · SendSafe schedule, caps, gaps, duplicate checks in Gmail
6 · RepliesClassified, referrals followed, answers drafted on Telegram

Nine n8n workflows and a Python research tool share one Google Sheet as the database, readable by a person and by code. A daily Telegram report shows what was sent, what came back and any problem with its fix.

Methods

Find companiesJobTech open job-ad API (Sweden), The Hub API, incubator and science-park portfolios, Hunter Discover
Find the personTeam and career pages, job ads that name the hiring manager. Founders at startups, team leads at large firms
Find the addressPublished > public GitHub commit address > company format inferred from real staff addresses
Confirm itDNS MX → catch-all test (one random address per domain) → self-hosted Reacher SMTP check → Reoon for Microsoft 365
Write itGemini Flash, Groq fallback. Each email names one concrete reason that links the company to my work
Guard itCode checks what can be checked (length, dates, names, banned phrases). The LLM must quote the text for every finding and match each claim to my profile facts

Engineering

  • Workflows as code: every workflow is generated from JavaScript and Markdown prompts, diffable and tested before deploy.
  • Tested like software: every code step runs against an anonymised sheet with all APIs mocked, then in a real n8n container.
  • Safe by default: content hash after QC, append-only log, Gmail "Sent" check before each send, auto-pause on quota errors.

What production taught me

  • Verifiers can be wrong. Microsoft 365 throttles the second recipient in one SMTP session, so real mailboxes looked invalid. Fix: a second verifier for those domains.
  • Quotas hit per minute, not per day. A burst of Gmail reads beside a send tripped the limit. Fix: each Gmail workflow got its own minute of the hour.
  • People write by hand too. An hourly Gmail-to-sheet sync logs my own emails, so the agent never sends on top of them.
  • Natural voice matters. The QC now flags phrases that read as machine-written, and the style rules were rewritten around plain, short sentences.
